# Current implementation status

This repository contains the first implementation skeleton and a functioning design for the MVP, but it has not been compiled in the creation environment.

Environment limitation:

- `.NET SDK`: not installed in the creation runtime.
- `npm install`: attempted, but dependency installation exceeded the available execution window.

The source is intended to be built on Windows with the .NET 8 SDK and Node.js. Use `scripts\\build.cmd` from the repository root.
